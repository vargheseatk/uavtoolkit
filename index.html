How each number is derived
Effective FX = amount debited ÷ invoice USD  ·  Freight+duty per $ = (freight + customs) ÷ invoice USD  ·  ITC per $ = import IGST ÷ invoice USD
Landed = cost$ × (FX + freight/$ + ITC/$)  ·  Suggested price = roundup( landed ÷ (1 − target margin) ) − charm offset
Output GST = price − price ÷ (1 + GST)  ·  Net GST payable = output GST − ITC  ·  P/L = price − net GST payable − landed  ·  Margin = P/L ÷ price

What this does — reads each product from the store's public Shopify data, downloads every gallery image renamed Brand-Product-Name_store_NN.jpg (the primary image has no number), and writes a WooCommerce import CSV next to them.

The store's rules are baked in — products import as draft, prices are never exported, stock is set in-stock with backorders off, categories are left blank for you to assign, the name starts with the brand, “Stock Number” becomes SKU Code, and specs become attribute columns only for variable products (simple products keep the spec list in the description). Every outbound link is stripped except YouTube.

Limits, honestly — a browser can only read stores that allow cross-origin requests, which covers Shopify (tested working, images included). Non-Shopify stores — SHOPLINE, and anything relying on the JSON-LD fallback — are blocked by the browser's same-origin policy and still need import_products.py locally. Saving straight into a folder needs Chrome or Edge; other browsers get a .zip instead.
